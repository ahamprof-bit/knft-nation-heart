Build a complete, production-style **website skeleton** for:

**Kalam Nation First Trust (KNFT)**

Tagline:

**Nation First. Humanity Always.**

## IMPORTANT — NO IMAGE GENERATION

Do NOT generate any AI images.

Do NOT create:

* AI-generated photos
* AI illustrations
* AI backgrounds
* AI logos
* AI videos
* stock-photo searches
* generated decorative images

For every image/video location, use a simple placeholder.

Example:

```text
[ IMAGE PLACEHOLDER ]
```

or use a local placeholder asset such as:

```text

```

The entire website must work correctly even without the real client media.

The client will later replace placeholders with:

* Official KNFT logo
* Client-provided photos
* Client-provided videos
* Project images
* Partner logos
